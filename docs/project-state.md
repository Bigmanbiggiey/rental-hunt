Implemented `React.lazy` route-level code splitting the same day (each real page its own 0.2–5.7KB chunk, `Suspense` fallback in `AppLayout`, a real barrel-import bug found via Rollup's own warning and fixed along the way — see commit `61a3793`), deployed it, then **re-measured rather than assumed**: two post-deploy Lighthouse runs came back **45** and **56** — both at or below the pre-fix baseline, not above it.
